# Getting Started

Welcome to your digital garden! This note will help you understand how to use this system.

## How to Add Notes

1. Open Obsidian
2. Create a new note (Cmd/Ctrl + N)
3. Write your content in Markdown
4. The Obsidian Git plugin will automatically sync every 5 minutes

## Linking Notes

Use `[[Note Name]]` to link to other notes. This creates connections in your knowledge graph.

For example: [[index|Home Page]]

## Tags

Add tags to organize your notes:

```yaml
---
tags:
  - category1
  - category2
---
```

## File Structure

```
📁 Your Vault
├── 📁 Example Notes/
├── 📁 Projects/
├── 📁 Ideas/
├── 📁 Learning/
└── index.md (home page)
```

## Tips

- 🌱 Start small - just write what you're thinking
- 🔗 Link often - connections emerge over time
- 🏷️ Tag consistently - helps with organization
- 📅 Date your notes - track your thinking evolution
