# Example Note with Links

This note demonstrates how linking works in your digital garden.

## Internal Links

Links to other notes create a knowledge graph:
- [[Getting Started]] - Your starting point
- [[index|Home]] - Back to the home page

## Backlinks

When you link to a note, it automatically shows up in the "Backlinks" section of that note. This creates bidirectional connections.

## The Power of Linking

As you write more notes and create more connections, patterns will emerge:
- Common themes will become visible
- Related ideas will cluster together
- Your thinking will become more interconnected
