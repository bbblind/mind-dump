# Andrea's Digital Garden 🌱

My personal knowledge base and digital garden, powered by [Obsidian](https://obsidian.md/) and [Quartz](https://quartz.jzhao.xyz/).

## 🌐 Live Site

Visit: [http://andrealabate.com/mind](http://andrealabate.com/mind)

## 🛠️ Tech Stack

- **Note-taking**: Obsidian
- **Static Site Generator**: Quartz 4.0
- **Version Control**: Git + GitHub
- **Auto-sync**: Obsidian Git Plugin
- **Hosting**: GitHub Pages
- **Deployment**: GitHub Actions (automatic)

## 🚀 How It Works

1. I write notes in Obsidian
2. Obsidian Git plugin automatically commits and pushes every 5 minutes
3. GitHub Actions builds the site with Quartz
4. Site deploys automatically to andrealabate.com/mind

## 📝 Local Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
