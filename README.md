# Andrea's Digital Garden 🧠

Your personal knowledge base, powered by Obsidian + Quartz.

## 🎯 Quick Start

### In Obsidian:

1. **Open the vault**: `/Users/al/Websites/obsidian`
2. **Navigate to `content/` folder** in the left sidebar
3. **Right-click on a folder** (cinema, music, poetry, lyrics, thoughts) → New note
4. **Name your note** (use dashes: `My-First-Note`)
5. **Write your content**
6. **Save** (Cmd+S)

**Your note will auto-sync to GitHub every 5 minutes!**

## 🔗 URLs

Files in `content/` become clean URLs:

```
content/cinema/Blade-Runner.md  →  /Blade-Runner
content/poetry/First-Poem.md    →  /First-Poem
content/thoughts/Random.md      →  /Random
```

No folder names in URLs - everything is flat!

## ✍️ Writing Tips

### Linking notes:
```markdown
See my thoughts on [[Blade-Runner]]
```

### Adding tags:
```markdown
---
title: My Note
tags:
  - cinema
  - scifi
---
```

### Frontmatter (optional):
```markdown
---
title: Custom Title
date: 2025-11-15
---
```

## 🔄 Auto-Sync

**Automatic**: Every 5 minutes, changes are pushed to GitHub

**Manual**: Press `Cmd+P` → "Obsidian Git: Backup"

## 🎨 Customizing

### Homepage:
Edit: `content/index.md`

### Site colors/theme:
Edit: `quartz.config.ts`

### Layout:
Edit: `quartz.layout.ts`

After changes, auto-sync will push them!

## ⚡ Philosophy

This is a **digital garden**, not a blog:
- Notes are living documents that evolve
- They can be unfinished, contradictory, experimental
- Focus on thinking-in-progress, not polished articles
- Links create unexpected connections
